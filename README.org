* AI Project Template

This repository contains reusable template files for AI-assisted coding projects.

It provides two project variants:

- =org-mode/= for projects that use Org-mode task and documentation files
- =markdown/= for projects that use Markdown task and documentation files

The repository root currently contains the Org-mode variant as the default template layout.

** Purpose

This repository is a starting point for projects that should be ready for AI-assisted development.

It includes:

- agent instructions
- repository-specific instruction files
- task tracking files
- task templates
- changelog files
- update scripts for shared AI configuration
- separate Markdown and Org-mode variants

** Variants

*** Org-mode variant

Use =org-mode/= when the target project should use Org-mode files.

This variant includes:

- =AGENTS.md=
- =CHANGELOG.org=
- =README.org=
- =.project/agents/AGENTS.md=
- =.project/agents/ai-notes.org=
- =.project/agents/repository.org=
- =.project/agents/update-ai-config-files.sh=
- =.project/tasks/template.org=
- =.project/tasks/todo.org=

*** Markdown variant

Use =markdown/= when the target project should use Markdown files.

This variant includes:

- =AGENTS.md=
- =CHANGELOG.md=
- =README.md=
- =.project/agents/AGENTS.md=
- =.project/agents/ai-notes.md=
- =.project/agents/repository.md=
- =.project/agents/update-ai-config-files.sh=
- =.project/tasks/template.md=
- =.project/tasks/todo.md=

** Using this template

This repository needs to be available locally. Use =./repo-template-init.sh= to initialize another project from one of the template variants.

The script must be run from inside the local =repo-template= repository.

Usage:

#+begin_src bash
  ./repo-template-init.sh markdown /path/to/target-project
  ./repo-template-init.sh org-mode /path/to/target-project
#+end_src

The script does the following:

- updates the local template repository with =git pull --ff-only=
- copies the selected variant into the target project with =rsync=
- overwrites existing files with the same names
- keeps other existing files in the target project untouched
- runs the target project's =.project/agents/update-ai-config-files.sh=
- prints the target project's Git status if the target is a Git repository

For Markdown-based projects:

#+begin_src bash
repo-template-init markdown /path/to/target-project
#+end_src

For Org-mode-based projects:

#+begin_src bash
repo-template-init org-mode /path/to/target-project
#+end_src

No files are staged or committed automatically.
